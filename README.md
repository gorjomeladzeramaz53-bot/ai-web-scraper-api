# AI Web Scraper & Intelligence API

ინტელექტუალური ვებ-სქრეიპერი და საიტების ანალიტიკური მიკროსერვისი, აგებული Python, FastAPI, BeautifulSoup4, HTTPX და SQLAlchemy-ზე.

## 🚀 ფუნქციონალი:
- **Asynchronous Web Scraping:** საიტების ასინქრონული სკანირება `httpx`-ის გამოყენებით.
- **HTML Parsing:** საიტის სათაურის, ტექსტის, ბმულებისა და სურათების ავტომატური გამოყოფა (`BeautifulSoup4`).
- **Database Integration:** დასქრეიპული ისტორიის ავტომატური შენახვა SQLite მონაცემთა ბაზაში (`SQLAlchemy`).
- **Data Analytics:** საიტის სათაურის, კონტენტის სნიპეტისა და ელემენტების რაოდენობის ანალიზი.

## 🛠 ტექნოლოგიები:
- **Python**
- **FastAPI**
- **SQLAlchemy (SQLite Database)**
- **HTTPX (Async HTTP Client)**
- **BeautifulSoup4**
- **Render (Cloud Deployment)**
- **Docker & Containerization**
